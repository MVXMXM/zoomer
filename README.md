# Zoomer (v0.1.7)

Semantic zoom for text — expand or contract content while preserving meaning using AI.

## Zoom Controls

`(-) Zoom out` Extrapolate into exhaustive detail

`(+) Zoom in` Distill to irreducible simplicity
