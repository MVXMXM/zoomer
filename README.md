# Zoomer (v0.1.12)

![Zoomer wordmark between a microscope and a telescope, above a zoom scale](app/opengraph-image.png)

Semantic zoom for text — expand or contract content while preserving meaning using AI.

## Zoom Controls

`(+) Zoom in` Add words and detail by moving the slider left.

`(−) Zoom out` Distill the text by moving the slider right.

Use Cmd/Ctrl + Plus or Minus with a selection to zoom just that passage.
