# Zoomer v0.1.0

Semantic zoom for text — expand or contract content while preserving meaning using AI.

## Features

- **Extrapolate (zoom out `⌘-`)**: Add detail and clarity to your text
- **Distill (zoom in `⌘+`)**: Simplify text to its core concepts
